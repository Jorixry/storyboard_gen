# 参考图提交说明

把采集表中引用的图片放在本目录，提交时保留目录结构。

## 命名

- 主参考图：`<template_id>.webp` 或 `<template_id>.png`
- 备用图：`<template_id>__alt_01.webp`
- 文件名必须与CSV中的 `reference_image_filename` 完全一致。

## 图片要求

- 推荐长边至少1280像素。
- 不提交聊天截图、网页UI截图或带大量无关文字的图片。
- 参考图应清楚表达景别、机位、人物站位和构图。
- 如果一张图不能表达运镜，可以额外提交起点/终点图：
  - `<template_id>__movement_start.webp`
  - `<template_id>__movement_end.webp`

## 来源与使用范围

采集表中必须写明：

- `原创/自摄`；
- `已购买授权`；
- 具体开放许可证；
- 或 `来源未知，仅供内部研究`。

来源未知或无法确认授权的图片不能进入公开产品。开发者会保留文件用于内部比对，但不会将其复制到用户可访问的产品资源中。
