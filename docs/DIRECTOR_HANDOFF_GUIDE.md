# Director Handoff - Developer Checklist

The self-contained packet to send to the project initiator is `handoff/director/`.

## Send

1. `handoff/director/README.md`
2. `handoff/director/shot-template-intake.blank.csv`
3. `handoff/director/shot-template-intake.example.csv`
4. `handoff/director/reference-images/README.md`

Send the entire folder so relative instructions remain intact. Ask the director to rename a copy of the blank CSV to `shot-template-intake.csv` and return it together with the `reference-images/` folder.

## First review batch

Request exactly three templates first:

- medium two-shot;
- over-the-shoulder A to B;
- over-the-shoulder B to A.

Do not request 8-12 templates until the first three have completed the intake -> mapping -> 3D review loop.

## Developer review boundary

The developer checks completeness, file/format integrity, representability and scope. The developer does not approve directing correctness. Only the project initiator/director may approve professional content.

## Required review outputs

For each mapped template, return to the director:

- director-view screenshot;
- camera-view screenshot;
- movement start/end screenshots;
- structured-parameter summary;
- unmapped requirements and open questions;
- template ID and version proposed for approval.

Keep status at `engineering_ready` or `director_review` until written approval is received.
